# GLM36 report qualification postprocessor

Source preparation only. This helper does not collect data, render figures, accept measurements or publish anything. Actual use requires the original full36 prepared package and independently accepted release evidence, including 3,780 measured successes, 756 scheduled warmups, 54 matched pairs and waited runner/outer terminal acceptance.

```sh
python3 -B /ABS/THIS/postprocess.py
python3 -B /ABS/THIS/postprocess.py --prepared /ABS/N/artifacts/ORIGINAL-PACKAGE --output /ABS/N/artifacts/EXCLUSIVE-QUALIFIED-COPY --execute
```

The default prints PLAN_ONLY. Explicit execution verifies the original complete FILES manifest, private regular file closure, PREPARED manifest binding, provenance counts/source/review bindings, seven exact source pins, root release gates, canonical 36 raw manifests/inner completion and saved metric rows, 54 pair groups and all three saved point/frontier views. Root release bindings are rehashed. This is a report-copy guard; it does not replace the full accepted native/default/GPU/transport/measurement review or independently reclassify the data.

Only generated `results/RESULTS.md` and `REPRODUCE.md` content changes. The original prepared payload and receipts stay untouched. The new exclusive copy retains all seven sources, raw evidence, scalar tables, coordinates, frontiers and figures byte-for-byte; it writes separate provenance/FILES/PREPARED plus an auditable `publication-qualification/` source/proposal bundle. Exact original PREPARED, release, FILES, provenance and both documents are retained under the new copy's `original/` directory. Input paths must be owned project-local artifacts; existing/overlapping output, symlinks, hardlinked files, specials, manifest drift and missing/duplicate report anchors are refused. Partial failure output is preserved.

The approved prose correction records C25's CUDA-default quantizer (no CuTeDSL-derived reciprocal/approximation claim), C17 residual GPU memory under sequential empty-application checks, exact September30/Torch2.13/pip14/install-failure then validation provenance, and scheduled warmup scope. Native measured AL/rate remain ratios of sums with full ordered measured coverage, excluding warmup, without the false completion=correct+verify identity.

The unmodified bundled reader regenerates its original historical report wording. The separate documented transformation produces the qualified report copy; do not claim those report bytes are the direct reader output. Numeric and figure reproduction is unchanged. The new copy remains pending independent review, visual/publication checks, preservation and root publication; this operation grants no cleanup authority. Old24 and historical N/A outputs remain immutable.

Private behavioral checks use explicitly synthetic temporary packages with the exact seven source bytes; their dummy cases/images are not benchmark or publication evidence. Run `python3 -B check.py` with stdout/stderr redirected to a new private review directory. No actual future package is processed by these checks.
